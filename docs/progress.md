# 开发纪事

109 轮迭代，从零到 0.58.19。这里只记过程和大坑；技术结论在 `findings.md`，
改了什么在 `CHANGELOG.md`。

## 缘起

想给自己做一个倒数日，但不想装那个广告和会员俱全的原版。于是按它的核心交互重写一个：
事件列表、天数计算、重复规则、提醒、桌面小组件，全部离线。

视觉上不想做成"又一个 Material 卡片列表"。方向定在冰川玻璃：单一淡蓝色相（H≈212°），
深浅靠明度，浮起和刻入两种质感，不用黑白。

## 第一阶段：从零到能装（第 1—9 轮）

先拆原版，弄清楚它怎么算天数、重复规则怎么落、小组件怎么刷新。结论记在 `findings.md` 前几节。

然后开始写。这一阶段定下来的东西后来几乎没改过：

- 倒数往回数（锚目标日），计时往后数（锚今天），两者共用一套 `CountdownMath`
- 数据落盘就一个 `events.json`，没有数据库
- 提醒走 `AlarmManager`，不依赖 WorkManager

第九轮打出第一个 APK。

## 第二阶段：把看得见的地方补齐（第 10—15 轮）

三层导航、调色盘、分类、自定义背景、动画、小组件、翻月翻年。0.5-beta 到 0.8-beta。

这一段开始出现"改一处坏一处"的现象，于是有了第一个自检脚本 `audit.py`——
它不编译代码，只对着源码做符号和资源对账。

## 第三阶段：0.13 — 0.37

数字滚动、顶栏玻璃托盘、卡片背景图（不是整屏背景）、动画整体重做、
设置页分组重构、全屏卡片页的数字可切。

这一阶段最耗时的不是功能，是动画。点击、返回、弹窗三条路径的时长和曲线各调了十几版。

## 第四阶段：0.58 系列，冰川玻璃成型

0.58 是改动最大的一版，把整套视觉重做了一遍：

- 玻璃拆成"浮起"和"刻入"两种，不再是统一的一张毛玻璃
- 反差色从"色相转 180°"改成按 4.5:1 算明度
- 字体子集化，思源黑体只保留用到的字形

同时补了预测式返回手势。这是全工程最容易改坏的一块，后面几轮有一半的 bug
出在这里，详见 `findings.md` 里关于 `BackHandler` 和 `backBusy` 的几节。

## 第五阶段：0.58.16 — 0.58.19

滑动翻月、背景色深浅滑块、渐隐带颜色修正、清理未使用导入、返回闸门兜底。

0.58.19 还没封包。其中"有概率所有组件都点不动"这一条只做到了"症状不会永久存在"，
没定位到具体是哪场手势漏了终点——如实记在 `CHANGELOG.md` 里。

## 关于验证

这台机器上没有模拟器也没有真机。所以整个开发过程的验证只有两种：

1. 编译通过（`compileDebugKotlin` 零警告）
2. 六个静态自检脚本

手感、动画、真机兼容性**没有验证过**。README 第九节列了已知限制，
其中几条（跨天不自动刷新、导入按 id 去重）是有意取舍，不是待办。

## 六个自检脚本

| 脚本 | 管什么 |
|---|---|
| `audit.py` | 符号和资源对不上：函数没声明、资源没引用、具名实参写错 |
| `parser_check.py` | 自然语言日期解析，56 个示例文案 |
| `math_check.py` | 天数计算的不变量，9 组 |
| `remind_check.py` | 提醒调度对拍，1712 项断言 |
| `stress_check.py` | 跑起来会不会崩：空指针、死循环、UI 层做 IO |
| `morph_check.py` | 卡片和列表行之间那套仿射变换，10 组 |

它们都不参与构建，只是开发时手动跑。CI 里也跑（`.github/workflows/ci.yml`）。
